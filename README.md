# CNKD 每日新闻插件

基于每日新闻API的AstrBot插件，可自动获取并发送每日新闻图片到指定群聊。

## 功能特性

- ✅ 自动获取每日新闻图片
- ✅ 支持定时发送（可设置具体时间）
- ✅ 支持白名单管理
- ✅ 支持管理员权限控制
- ✅ 支持跳过周末
- ✅ 支持多时区
- ✅ 支持失败重试
- ✅ 支持缓存机制

## 安装方法

1. 将插件文件夹 `astrbot_plugin_CNKD_NEWS` 放入AstrBot的插件目录
2. 确保已安装依赖：`pip install aiohttp`
3. 重启AstrBot或重载插件

## 配置说明

插件支持以下配置：

- **enabled**: 插件总开关
- **whitelist**: 允许使用插件的群聊UMO列表
- **admin_users**: 管理员用户ID列表
- **default_send_time**: 默认定时发送时间
- **timezone**: 时区设置
- **skip_weekend**: 是否跳过周末
- **retry_times**: 失败重试次数
- **timeout**: API请求超时时间

## 使用命令

### 基础命令
- `/新闻帮助` - 显示帮助信息
- `/新闻` - 立即发送今日新闻
- `/新闻状态` - 查看插件状态

### 定时任务命令
- `/新闻定时 HH:MM` - 设置本群定时发送时间
- `/新闻定时关闭` - 关闭本群定时发送
- `/新闻定时列表` - 查看所有定时任务

### 管理员命令
- `/新闻白名单添加 [UMO]` - 添加群组到白名单
- `/新闻白名单删除 [UMO]` - 从白名单移除群组
- `/新闻白名单列表` - 查看白名单
- `/新闻管理员添加 [UID]` - 添加管理员
- `/新闻管理员删除 [UID]` - 移除管理员

## 注意事项

1. 每日新闻API可能有请求限制，请合理使用
2. 建议将超时时间设置为至少10秒
3. 插件会自动缓存新闻图片，避免重复请求
4. 周末跳过功能默认开启

## API说明

插件使用以下API获取新闻图片：
- 地址：https://uapis.cn/api/v1/daily/news-image
- 方法：GET
- 返回：image/jpeg格式的图片二进制数据
